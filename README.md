# 🔮 El Oráculo Meteorológico

**Inteligencia Meteorológica Táctica para Viajeros Serios.**

[![Deploy to Cloudflare Pages](https://img.shields.io/badge/Deploy-Cloudflare_Pages-orange?style=flat-square&logo=cloudflare)](https://oraculo.pages.dev)
[![Standard](https://img.shields.io/badge/Standard-PWA_Ready-brightgreen?style=flat-square)](https://web.dev/progressive-web-apps/)

El Oráculo no es una aplicación de clima convencional que vende esperanza. Es una herramienta de **análisis de riesgos** que consulta los últimos 20 años de registros históricos para decirte qué es lo peor que podría pasar en tu destino.

---

## 📡 Capacidades Tácticas

- **Reconocimiento Histórico (20A):** Compara cada día de tu viaje con el mismo día de las últimas dos décadas.
- **Índice de Frustración:** Cálculo algorítmico de la probabilidad de lluvia acumulada.
- **Ventana de Oro (IDEAL):** Identificación estadística del mejor momento para actividades críticas.
- **Punto Crítico (EVITAR):** Alerta automática sobre el día con mayor riesgo de precipitaciones.
- **Métricas de Supervivencia:** Sensación térmica real, Índice UV máximo y velocidad del viento.

## 🛠️ Stack Tecnológico

- **Frontend:** HTML5, CSS3 (Custom Variables), JavaScript Vanilla.
- **API:** [Open-Meteo](https://open-meteo.com/) (Geocoding, Forecast & Archive).
- **Iconografía:** [Lucide Icons](https://lucide.dev/).
- **Distribución:** PWA (Progressive Web App) con Service Worker para carga instantánea.

## 🚀 Instalación y Despliegue

La aplicación es un **Single File App** (PWA), lo que facilita su despliegue en segundos:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/pixelatumente/el-oraculo-meteorologico.git
   ```
2. Abre `index.html` en cualquier navegador o despliega la carpeta en **Cloudflare Pages**.

## 🛡️ Manual de Operaciones

- **Tactical Forecast:** Lo que el satélite dice que pasará (Predicción Real).
- **Worst Case:** Lo que la historia demuestra que ha pasado (Peor Caso).
- **Kit de Supervivencia:** Recomendaciones de equipaje basadas en los récords históricos de la ubicación.
